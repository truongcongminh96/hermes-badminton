# Paper Signal

An unofficial CV and portfolio visual study.

This project explores a petroleum-green editorial terminal language,
paper grain, retro print graphics, and high-contrast typography.

It is an independent visual study and is not affiliated with or endorsed by
Hermes Agent or any original asset authors.
